# 长期价值研究方法论

本文件定义豆角长期价值研究系统的详细研究方法。Project Instructions 负责最高级行为规则；本文件负责“研究具体怎么做”。若冲突，以 Project Instructions 为准。

研究完成后的多平台内容转换统一交给 `$produce-doujiao-value-content`。下游内容规则必须完整映射本方法论第 1—13 节的研究产出，只能重组、压缩和解释已经形成的证据与结论，不得重新计算口径、补造缺失项或改变研究判断。本文件第 14 节定义文字研究报告结构，不要求自媒体内容沿用相同章节顺序。以后修改本方法论的研究维度、术语或最终结论字段时，必须同步检查内容 Skill 的映射表。

## 1. 理解生意
用简单语言说明公司向谁提供什么价值、客户为何付钱、收入和现金如何产生。分析产品、客户、地区、渠道、供应链、收入模式、成本结构、单位经济性、营运资金、资本密集度、周期性、季节性和监管。

拆分增长来自涨价、销量、产品组合、有机扩张、并购还是汇率。识别客户、供应商、渠道、产品、地区和关键人物集中风险。

必须回答：如果不看股票代码，这是不是一个愿意长期拥有的生意？

## 2. 十年财务与会计质量
默认建立最近十个完整财年的统一币种和实际原始数值表，并补充最新季度与近12个月（TTM）。机器数据中的金额使用报告币种实际数值、股数使用实际股数、比例使用十进制小数；面向读者的报告再按中文习惯换算为万元、亿元、万股、亿股和百分比。

至少包括：
- 营收及增长；
- 毛利率、营业利润率、净利率；
- 净利润、经营现金流、资本开支；
- 标准 FCF、股东调整后 FCF、Owner Earnings；
- ROIC、ROE、增量资本回报率；
- 现金、债务、净债务、利息覆盖；
- SBC、稀释后股份数、每股利润、每股 FCF；
- 分红、回购、并购、资产出售和债务变化。

检查利润现金转化、应收与库存、合同资产、预付款、供应链融资、营运资金释放、有机与并购增长、价格与销量、股份稀释、反复出现的“一次性”费用、资本化支出和非 GAAP 调整。

区分管理能力、行业顺风、杠杆和会计口径的影响。若公司发生财年变更、拆股、重组、报表重述或重大并购，先统一口径再比较。

## 3. 自由现金流与 Owner Earnings
同时报告并对账：

标准 FCF = 经营现金流 − 总资本开支。

股东调整后 FCF：把 SBC 视为真实经济成本，结合稀释、员工行权和回购效果调整，避免重复扣除。

Owner Earnings = 净利润 + 折旧摊销及适当非现金费用 − 维持性资本开支 − 维持竞争地位所需新增营运资金。

银行、保险、支付信贷平台等金融企业不机械套用“经营现金流 − 资本开支”。必须单独估算股东可分配现金（FCFE）：

股东可分配现金 = 正常化普通股股东净利润 − 为支持资产、风险加权资产或保费增长并维持目标监管资本所需留存的普通股权益。

该口径必须列出基准期普通股净利润、目标资本约束、必要留存资本、可分配比例、股东可分配现金总额和稀释后每股金额。股息和回购只用于校验实际分配，不自动等于可分配能力；EPS 只描述会计盈利，不是 DCF 的现金流输入。

区分维持性与扩张性资本开支。不能准确区分时，根据公司披露、折旧、产能、门店、设备寿命和同行给出区间，说明方法和不确定性。依赖持续收购维持收入的公司，应估算“维持性并购”。

评价十年正 FCF 年份比例、中位数、增长、波动、最差年份、FCF 利润率、现金转化率及周期底部表现。判断现金是否足以覆盖利息、到期债务、必要投资和分红，是否依赖 SBC、资产出售、融资或不可持续营运资金变化。

## 4. ROIC 与再投资跑道
普通企业优先使用：

ROIC = NOPAT ÷ 平均投入资本

增量资本回报率 = 一段时期 NOPAT 增加额 ÷ 同期投入资本增加额

分析十年 ROIC 中位数、最低值、波动、超过资本成本的年份和幅度，以及最近三至五年增量回报。

判断高回报来自真实优势，还是杠杆、负营运资本、费用化研发、减值或过小分母。并购型企业同时观察含商誉和剔除商誉 ROIC；解释 ROE 因负债、回购或负净资产造成的失真。

15%—20% 仅是部分普通企业的参考区间。核心是长期回报是否显著高于资本成本，新增资本能否继续获得高回报。

再投资跑道质量 = 可再投资资本规模 × 增量资本回报率 × 可持续年限。

结合市场容量、渗透率、产能、新产品、地域扩张、竞争与内部蚕食，将企业区分为：
- 高回报长跑道复利型；
- 高回报但空间有限的现金牛；
- 重资本增长型；
- 低回报价值毁灭型。

现金牛若能合理分红或在低估时回购，仍可能是优秀生意。

## 5. 护城河
分别评估：
- 定价权；
- 转换成本；
- 网络效应；
- 规模或成本优势；
- 品牌、专利、牌照；
- 渠道、生态与数据；
- 流程与文化。

每项给出支持证据、反证、0—5 分、趋势、置信度和最可能的破坏因素。

定价权必须由提价后的销量、留存、份额、客户行为和利润率验证；高毛利、高 ROIC 或高份额本身不等于护城河。

必须阅读主要竞争对手资料，并分析替代品、技术、监管以及上下游议价能力。

## 6. 长期生存与 Too Hard
必须回答：
1. 十年后产品或服务是否大概率仍被需要？
2. 公司相对竞争优势届时更强、相同还是更弱？

分析需求持久性、替代风险、行业变化速度、资产负债表韧性、集中度、关键人物、供应链、监管和社会许可。

至少在衰退、价格战、成本上涨、技术替代、核心 CEO 离任和融资市场关闭情景下压力测试。

若商业模式无法验证，现金流依赖难预测技术、监管或商品价格，行业变化过快，结构与关联交易过于复杂，数据长期缺失或披露不可靠，合理假设产生相反结论，DCF 主要依赖遥远终值，或必须准确预测多个低确定性变量，主动归入 Too Hard。

说明难点、缺失证据、移出条件及不行动理由。

## 7. 文化、管理层与“不做清单”
搜集长期股东信、业绩会、采访、演讲、薪酬和资本配置记录，从行动判断：
- 战略是否专注；
- 是否克制并购、举债和扩张；
- 是否客户与股东导向；
- 是否坦诚承认错误、坏消息和不确定性；
- 决策是否理性长期；
- 激励会诱导什么行为；
- 组织能否跨越创始人或明星 CEO。

制作“承诺—结果”时间线和“不做清单”：管理层明确不做什么，公司实际拒绝过什么，是否违反边界。

重点检查无关跨界、低回报并购、过度杠杆、高价回购、激进会计，以及为短期指标损害客户或产品。没有公开清单不是负面证据，长期行为边界才是关键。

## 8. 资本配置与回购
追踪十年现金来源和去向，评价核心业务再投资回报、并购价格与结果、分红、债务和风险管理，以及是否为规模牺牲每股价值。

建立回购明细账：
- 年度金额；
- 估算均价；
- 回购股数；
- SBC/期权/并购发行；
- 期末及稀释后股份数；
- 实际净股份变化；
- 净回购收益率；
- 资金来源；
- 回购价格相对当时价值区间的位置。

区分真正净回购、仅抵消 SBC、低估时创造价值、高估时浪费现金及举债抬升 EPS。使用当时信息，避免事后偏见。

## 9. 会计、治理与财务风险
检查：
- 审计师更换、重述、延迟披露、内控缺陷；
- 收入确认、资本化支出、非 GAAP 调整；
- 保理、供应链融资、表外负债；
- 关联交易、内部人交易、股权质押；
- 少数股东待遇、双层股权、董事会独立性、控制人；
- 债务利率/币种/契约/抵押/期限与再融资；
- 诉讼、税务、养老金、租赁和或有负债。

重大诚信、治理、财务韧性或数据可靠性问题具有否决权。

## 10. 估值
写明估值日、股价时间戳、币种、稀释后股数、净债务和企业价值。

至少使用：
- 历史与正常化 PE；
- FCF Yield；
- Owner Earnings Yield；
- EV/EBIT；
- 仅在有经济意义时使用 PB 或 P/TBV；
- 悲观、基准、乐观 DCF；
- Reverse DCF。

必要时使用分部估值、资产价值、重置价值或周期中枢盈利。

内在价值必须从可分配现金开始，先确定业务与价值口径，再选择 FCFF、FCFE、Owner Earnings 或金融企业股东可分配现金。每份正式报告都必须用一张“DCF 输入表”明确列出：

- 现金流口径和基准期间；
- 初期可分配现金总额、稀释后股数和初期每股现金流；
- 显性预测期、初期现金流增长、折现率或股权成本；
- 终值增长、终值占总价值比例和总额到每股价值的桥接。

普通企业继续展示收入增长、利润率、税率、折旧摊销、资本开支和营运资金如何形成 FCFF、FCFE 或 Owner Earnings；金融企业展示正常化普通股净利润、资本增长需求、目标监管资本和必要留存如何形成 FCFE。不得把 EPS、PE 或退出倍数伪装成 DCF 现金流；它们只能作为结果交叉验证。

悲观、基准、乐观情景使用同一现金流口径，展示现金流增长、折现率、终值增长、每股价值、终值占比和敏感性。Reverse DCF 从现价反推市场隐含的可分配现金增长、留存/资本强度或现金回报，并与历史、资本约束和行业容量比较；不得只反推 EPS 增长。

报告合理价值区间及不同情景长期年化回报。若终值占比过高、现金流口径无法可靠建立或小幅参数变化即可翻转结论，降低置信度、扩大区间或归入 Too Hard。

安全边际必须与业务稳定性、负债、治理和估值不确定性匹配。历史和同行倍数仅作交叉验证。

## 11. Pre-Mortem 与反证
报告结尾回答：“假设十年后公司内在价值大幅下降甚至破产，最可能发生了什么？”

至少列出五条失败路径，每项给出概率、影响、时间范围、最早预警指标、可逆性和管理层缓解能力。

至少覆盖：
- 债务与再融资；
- 单点依赖；
- 技术替代；
- 监管与诉讼；
- 护城河收窄；
- 资本配置错误；
- 诚信、激励与继任。

区分“公司破产”和“公司仍存在但股东长期回报很差”。

同时列出最强反方观点、最脆弱的三个假设、推翻投资论点的新证据，以及未来持续监控的 5—10 个领先指标。

## 12. 行业适配
### 银行
ROE/ROTCE、净息差、存款成本和稳定性、信贷质量、拨备、资本充足率、流动性、P/TBV。估值优先用正常化普通股净利润扣除维持目标 CET1 所需留存资本得到 FCFE，并以股息、回购、P/TBV 或剩余收益交叉验证。

### 保险
承保利润、综合成本率、准备金、浮存金成本、偿付能力、投资风险、每股账面价值增长。估值优先用正常化普通股利润扣除维持偿付能力和业务增长所需权益资本得到 FCFE，并以股息、账面价值或剩余收益交叉验证。

### REIT
FFO/AFFO、同店 NOI、入住率、租约、租户集中、NAV、利息覆盖和债务期限。

### 资源与强周期
周期中枢价格、成本曲线、储量寿命、维持性资本开支和资产负债表压力测试，不用周期顶部盈利估值。

### 平台、软件与研发密集企业
重点检查 SBC、费用化研发、留存、单位经济性及负营运资本对 ROIC/FCF 的扭曲。

其他行业在研究开始时先说明专属指标。

## 13. 评分与最终结论
最终评分必须以明确表格分别评价以下八个维度：
1. 生意可理解性；
2. 财务与现金流；
3. ROIC 与再投资；
4. 护城河；
5. 长期生存；
6. 文化、管理层和资本配置；
7. 会计、治理和资产负债表；
8. 估值与安全边际。

正式 `research-report.md` 固定使用表头“维度｜评分 / 5｜置信度｜核心证据｜最强反证”。每项给出 0—5 分、置信度高/中/低、核心证据和主要反证。评分不是机械交易信号。

一页式结论和最终结论都必须以明确字段给出，且前后一致：
- 企业质量：优秀 / 良好 / 一般 / 较差 / 无法判断；
- 估值状态：明显低估 / 可能低估 / 接近合理 / 偏高 / 无法判断；
- 研究状态：深入研究 / 观察名单 / 等待价格 / 放弃 / Too Hard；
- 置信度；
- 2—4 项关键前提；
- thesis breakers 与推翻条件。

## 14. 文字报告结构

`research-report.md` 是可独立交付的正式研究文档。读者不打开 `company.json`、`evidence-ledger.json`、`calculation-ledger.json` 或 `research-completeness.md`，仍必须能理解商业、数据口径、关键计算、风险和结论，并能直接访问及定位支持关键主张的来源。伴随文件是补充、交叉校验和机械复算层，不是报告正文的替代品；不得以“完整 URL 见 `company.json.sources`”“详见台账”等表述卸载报告的可核实义务。

正式报告使用可见的纯 Markdown；除无属性的 `<br>` / `<br/>` 换行外，不使用原始 HTML。不得用 fenced code、HTML comment、`hidden`、`display:none`、`template`、`script`、`style` 或其他不可见容器伪造标题、表格或正文覆盖。

关键数字和关键主张在首次出现处就地引用直接链接或标注 `SRC-*`。采用 `SRC-*` 时，精确定位由文末“来源定位索引”统一解析，正文不必重复；索引固定使用表头“来源ID｜标题｜发布者/类型｜日期/期间｜URL｜页码/章节定位”，每个 ID 逐项给出标题、发布者与来源类型、发布日期或适用期间、直接 URL，以及页码、监管文件 Item/表号、稳定章节或时间戳中的至少一项精确定位。仅列文档名、首页 URL 而无定位，或把 URL 推给其他文件，均不算完成来源索引。

缩写、行业指标和非通用术语首次出现时必须解释。每项结论先用通俗语言说明对企业和股东意味着什么，再展开技术口径、公式、行业术语和限制。

报告必须按以下顺序完整包含 16 节；每节必须有实质正文，不得合并、缺省或用占位语句代替：
1. 一页式结论：明确展示企业质量、估值状态、研究状态、置信度、2—4 项关键前提和 thesis breakers；
2. 身份、数据截至日、完整度和缺失项；
3. 商业模式与行业结构；
4. 十年财务表和关键趋势；
5. FCF、股东调整后 FCF 与 Owner Earnings；
6. ROIC 与再投资跑道；
7. 逐维护城河：固定使用表头“维度｜评分 / 5｜趋势｜置信度｜支持证据｜最强反证｜最可能的破坏因素”，每个维度分别给出支持证据、最强反证、0—5 分、趋势、置信度和最可能的破坏因素；
8. 十年后需求与长期生存；
9. 文化、不做清单、管理层和资本配置；
10. 回购明细账；
11. 会计、治理、负债和红旗；
12. 估值、Reverse DCF、敏感性和情景回报：先给 DCF 输入表，明确现金流口径、基准期初期现金流总额与每股金额、稀释后股数、显性期、初期增长、折现率、终值增长和终值占比，再给三情景、敏感性、Reverse DCF 及倍数交叉验证；
13. 完整 Pre-Mortem：固定使用表头“失败路径｜概率｜影响｜期限｜最早预警｜可逆性｜管理层缓解”，至少五条失败路径逐项填满；另以“最强反方观点：”“三个最脆弱假设：”“Thesis breakers：”“破产路径：”“存活但股东回报差：”五个明确标签分别列示，并与结构化风险和结论逐项一致；
14. 尚待调查问题；
