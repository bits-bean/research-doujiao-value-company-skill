# 收入来源与十年收入结构

首次完整研究、增量更新及修复受影响的营收数据时读取本文件。回答：过去十个完整财年，公司分别靠什么取得收入，各部分每年贡献多少钱、占总营收多少，结构怎样变化及为什么。研究层负责取证、计算、解释与图表交接；网页由 system 渲染。

## 官方取数与可比性

- 以最近十个完整财年为窗口，逐年建立“财年 → 年报 / 监管年度申报及收入附注 → 页码或表号”的来源覆盖表。实际打开覆盖各年的官方财报；一份较新财报的多年度比较表可覆盖多个财年，但不得据最新一年比例倒推历史。最新季度、TTM 另列，不混进十年年度序列。
- 先依据财报选择最能解释赚钱方式的一组收入构成，可以是收入性质、产品 / 服务或经营分部；类别数量随真实披露确定。主序列只采用一个互斥、可加总的维度，不能把产品、地区和分部收入混加，也不能同时加总子项与包含它的小计。需要另一维度时单独分析。
- 每年保留各项报表原名、展示名称、金额、总营收、口径、来源 ID 与精确定位。统一财年、合并范围、币种及总额 / 净额口径；说明采用外部客户收入还是含内部交易的分部收入，后者必须保留官方抵销项。金融等行业按其披露的净收入定义拆分，不把利息收入总额混进以净利息为组成部分的总额。
- 优先使用最新官方重述的可比历史值，并保留原披露值、重述值、适用年度和来源。除年报外，还应检查重分类实施期的业绩补充表、投资者材料及监管附件是否重列更早年份。分别记录“新口径实施时间”和“已按新口径重列的最早年份”，不能将二者混为一谈。仅更名且含义不变时可统一名称；合并、拆分、处置或会计政策变化，只有官方可复核映射或重述才能接成同一序列。无法统一时保留原分类并标注断点，不能按当前结构回填旧年。
- 上市 / 存续不足十年或历史披露不足时，搜寻可得官方历史材料，列出各缺失年度、类别、已查来源及影响，展示实际覆盖长度。未披露用 `null`，真实零值需有依据；不能填零、插值或把无法识别的缺口塞进“其他”。“其他”仅来自官方披露，或来自有来源、已完整列明的剩余项目之和，并标明为计算汇总。

## 金额、占比与变化计算

- 各年逐项计算 `占比 = 该项收入 / 同年同口径总营收`。金额存报告币种实际数值，比例存 decimal；总营收为零或缺失时占比为 `null`，不创建除零或缺输入的计算。负值保留原符号并解释，不取绝对值、不截成零。
- 逐年复核“各组成项目之和（含适用的官方抵销 / 抵减）= 总营收”，并与 `financials[].revenue` 对齐。若主维度确有不同的官方分母，须提供到合并营收的有来源调节桥，不能悄悄更换分母。完整、可比且分母为正的构成占比应合计为 100%；只允许原披露舍入精度可以解释并已量化的差异，不用任意百分比容差或无来源残差凑平。
- 使用按原披露精度还原的金额计算占比，计算前不再作展示舍入，也不补造更高精度；最后才按中文展示单位换算。展示舍入导致总和略偏离 100% 时注明原因；缺项年份不得把已知项重新归一化为 100%。
- 在 `calculation-ledger.json.calculations[]` 中按财年保存占比、构成合计及与披露总额之差，以及报告实际使用的结构变化计算。沿用 `metric: custom`、`period`、`formula`、`inputs`、`result`、`source_ids`、`review_method` 契约；复核说明绑定具体构成名称、分母定义和来源定位。缺失值与不能计算的原因留在数据和完整度说明，不伪造有限数值结果。
- 在报告现有商业模式章节中给出逐年“各项金额 + 占比 + 总营收”表及就地来源，不增加或替换固定 16 节，也不在十年财务模块重复展示同一图。使用三级小节“收入结构演变”保存数据与比较口径，再使用三级小节“收入结构的经营含义”承载解读；编号随报告顺序确定。
- “收入结构的经营含义”包含引入段及 2—3 个四级小标题，分别说明赚钱的结构如何变化、商业模式及战略重心发生什么变化、观察哪些条件才能验证该判断。先说明金额增长与占比变化，再讨论利润质量、业务依赖和长期韧性；区分事实、管理层披露与研究推断，有来源和推翻条件。结构比例变化本身不能证明战略转向，须结合产品、客户、渠道、投资或管理层行动的证据。段尾以“比较边界”明确重分类、并购 / 处置与不可比区间；只在可比区间计算增长，份额变化用百分点。

## 结构化交接

现有 Schema 2.4.0 的 `segments[]` 可按 `period + name` 保存一个主拆分维度的多年序列，不限于最新一年：

| 信息 | 现有字段与约束 |
|---|---|
| 财年与收入类别 | `period` 与 `financials` 同期；`name` 在含义一致的可比区间保持稳定，同一财年同名唯一 |
| 金额与占比 | `revenue` 为实际金额或 `null`；每项显式填写 `revenue_share` 为 decimal 或 `null` |
| 口径、断点和来源 | `notes` 说明主拆分维度、原报表名称、分母差异、重述 / 缺失与可比区间；`source_ids` 解析到同一 `company.json.sources`，精确定位由台账保留 |

收入性质拆分不能被描述成公司法定报告分部；未披露的分部利润和增长率不由收入比例推算。当前 `segments` 没有独立维度、分类版本和分母字段，不能把多套重叠拆分塞进同一数组后让网站猜测。单一主维度之外的数据保留在报告和台账；确实需要额外结构时写 `schema-gap-report.md`，说明网页缺口，不私改只读 Schema、不自增字段或静默改义。`industry_metrics` 仅保存适用的行业指标，不能用它绕过维度缺口；单年桑基也不能代替十年结构序列。

最新完整财年的每个收入类别还须有可追溯的通俗说明。沿用 `segments[].notes` 的独立标记行“付款方：”“付费原因：”“增长驱动：”“口径提醒：”，各标记只出现一次；前三项必填，第四项在需要时填写。说明谁付钱、为何支付、金额受哪些经营因素驱动，以及总额 / 净额、计算汇总或内部交易等边界；由 `source_ids` 及台账精确定位支撑。不要把名称翻译当解释，不按固定四张卡凑类别。抵销、套期保值等会计调整明确说明不是客户付费项目。

## 商业模式的网页交接

网页主标题统一为“商业模式”，英文眉题统一为 `BUSINESS MODEL`。默认顺序为“收入来源”→“价值如何创造、传递与回收”→“钱从哪来，又到哪去”→“收入结构演变”；分别承载当年构成、价值交换、利润流向和十年结构及经营解读。章节角色和数据要求适用于所有公司，不以已有某家公司样例或固定收入类别为前提。网页次序不改变研究报告固定 16 节和内容导出固定图表身份 / 次序。

“收入来源”交接为最新完整财年一张可交互环形图及按真实类别生成的说明卡。图表与桑基图使用相同内容宽度；环心放期间与金额总额，类别和百分比放环外，以引导线对应各色块。沿用十年图的类别色。细小份额不设置最小扇区角度、不合并或省略；标签按可用宽度换行、分列避让，必要时增加高度。悬停、键盘聚焦与点按均可查看金额、占比并突出对应项目，兼顾触屏与减少动画偏好。

负调整不得画成正扇区。所有正项勾稽完整但存在官方负调整时，环形图可以明确采用“调整前收入”为分母，环心和外置百分比均使用该口径，同时单列有符号调整及到报表总营收的调节桥；说明卡仍明确列示相对于报表总营收的占比。冻结数据和十年图保留原始符号及净分母，不能为环图改写财务数据。若无法建立完整、同口径的桥，展示已知金额及缺口说明，不归一化为完整构成。

“价值如何创造、传递与回收”另按 [business-model-actors.md](business-model-actors.md) 交接当前公司的具体对象、关系和插图语义。收入来源说明能解释谁付款，但不能代替完整价值交换图谱；不得以通用角色名或固定三张插图填补研究缺口。

## 网页图表选择与验收

- 默认只展示**一张水平金额堆积柱状图，同时标注金额与占比**：财年从上到下由早到晚，横轴为金额，所有年份使用同一线性金额尺度和零基线；柱长体现各年总营收差异，每个色块宽度与该项金额成比例。构成完整、项目非负且已勾稽时，柱长等于总营收。图高按行数和标签需求紧凑安排，不使用过高的纵向柱。口径断点须明确分界，不能把不可比区间的结构变化全部解释为业务变化。
- 每年直接显示各项金额、百分比及年度总营收，并明确金额使用亿元等中文展示单位；百分比始终以各年同口径总营收为分母。默认不保留“金额 / 占比”视角切换，不使用等长的 100% 柱隐藏总营收差异，也不能要求读者先悬停才看到另一项数值。
- 标签须保持足够字号、对比度与间距。宽屏可将金额和占比放入足够宽的色块；窄屏及细小色块在同年柱下用同色标签列示数值，并按类别数自适应换行。主图不依赖横向滚动，不以过小字号挤入十年数据；明细表可单独横向滚动。不能为塞入标签设置最小块宽、改变金额比例、挤叠、截断或静默省略。悬停 / 点按 / 键盘选择可补充该年各项名称、金额、占比、总营收、口径及来源，并提供可直接阅读的年度数据表。
- 跨年保持相同类别的颜色和堆积顺序；分类新增、合并、更名或断点有清楚注记。类别过多时可使用按类别分面的小图；为可读性汇总小项必须保留逐项数据、披露汇总规则且跨年一致，不固定类别数量。
- 负项采用保留符号的发散柱状图 / 分面金额图并附占比表；缺项或不可比区间展示明确缺口、分段图或数据表。不能强制归一化，也不能用连续填色掩盖断点。十年变化不能只用最新一年饼图 / 环图或单年桑基表达。
- “收入结构演变”的读图说明、口径与可比性、经营解读及详细来源默认收在“读图说明、口径与经营解读”折叠区内；数据图、年度总额与可读取的明细入口保留。折叠只改变网页初始呈现，不删除正文、台账或来源。
- 在 `research-completeness.md` 记录主维度、覆盖年份、图表选择与理由、可比性、缺口、数据字段及计算记录的对应关系，供 system 从同一冻结版本渲染。这里交付的是图表输入和展示意图；不调用渲染器、不把交接标为网页已上线。
- 冻结前做语义验收：十年官方来源覆盖或缺口解释齐全，金额 / 占比 / 分母逐年可复算，类别互斥、可比区间和断点真实，报告表格与结构化数据一致，最新来源解释和战略判断均有证据。现有 Schema 和通用计算校验通过不能代替这些检查；复核结论和例外留在完整度说明。网页任务另行检查实际渲染与交互，覆盖所有现有公司、宽窄屏、细小份额、负调整、分类断点及缺失情形，核对环图分母与调节桥、同图金额和占比、年度总额、总柱长与总营收的比例、外置标签及折叠状态后才能称图表完成。
